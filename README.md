# Radiolab Academy

Web de estudio independiente, sin afiliación oficial a ILERNA. Incluye 17 módulos y lecciones introductorias de muestra, test, repaso de errores, perfiles y foro.

Publicación: GitHub Pages desde la rama `main` y carpeta `/ (root)`. Backend: proyecto privado TPIDMN en Supabase, conectado mediante clave pública en `config.js`. Los roles administrativos se asignan exclusivamente desde Supabase (tabla `admin_users`), nunca desde el navegador.

Para evitar problemas de copyright, los documentos originales del Drive no se distribuyen aquí: el contenido inicial es original y de muestra; los contenidos extensos deberán revisarse antes de publicarse. Las clasificaciones y desafíos son recreativos; el resultado se calcula en el cliente, no ofrece garantías contra trampas. Los duelos son asíncronos, no Kahoot en directo.
